Cảm ơn bạn đã đăng ký. pdf-translation-layout v3.1.0 dịch PDF tiếng Anh sang tiếng Việt mà vẫn giữ nguyên bố cục trang, chữ thật bôi đen được, kèm bản song ngữ và phiếu kiểm định lỗi dấu, tràn khung. Chính trợ lý AI của bạn là người dịch.

Tải pdf-translation-layout.zip (3,6 MB)

Dùng trong Claude.ai, không cần cài gì

01Tải file zip ở nút trên. Không cần giải nén.
02Vào claude.ai → Settings → Capabilities, bật Code execution and file creation.
03Vào Customize → Skills, bấm + → Create skill → Upload a skill, chọn file zip vừa tải.
04Mở cuộc trò chuyện mới, đính kèm PDF và nhắn: “Dịch file này sang tiếng Việt, giữ nguyên bố cục”. Tài liệu dài, Claude dịch theo lô và mời bạn nhắn “tiếp”.

Dùng được với gói Free, Pro, Max; Claude Desktop làm y như vậy. Không tốn thêm tiền, chỉ dùng hạn mức gói Claude bạn đang có. Hướng dẫn có hình: pdf.huynhanhthuan.com/dung-voi-claude.

Bản dịch dùng để đọc hiểu cá nhân; mỗi trang có dòng chân trang nhỏ ghi rõ điều này. Muốn đăng hoặc chia sẻ công khai bản dịch sách, bài báo có bản quyền, bạn cần sự đồng ý của chủ sở hữu bản quyền.
