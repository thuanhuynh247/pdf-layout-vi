pdf-translation-layout v3.0.1

Chào An,

Cảm ơn bạn đã đăng ký. Đây là gói kỹ năng pdf-translation-layout v3.0.1: dịch PDF sang tiếng Việt mà vẫn giữ nguyên bố cục, chữ vector thật, xuất bản song ngữ và video đọc sách.

Tải pdf-translation-layout-v3.0.1.zip (550 KB)

Cài cho Claude Code trong 5 phút

01Giải nén tệp zip, bạn có thư mục pdf-translation-layout.
02Mở terminal trong thư mục đó, chạy pip install -r requirements.txt (cần Python 3.10 trở lên).
03Gõ claude ngay trong thư mục: Claude Code tự đọc tệp CLAUDE.md. Muốn dùng ở mọi nơi, chép thư mục vào ~/.claude/skills/.
04Ra lệnh: “Dịch ./bao-cao.pdf sang tiếng Việt, giữ nguyên layout, rồi chạy QA.”

Hướng dẫn chi tiết nằm trong tệp GUIDE_CLAUDE.md của gói.
